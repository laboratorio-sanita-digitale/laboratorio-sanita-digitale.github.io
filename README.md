# Laboratorio Sanità Digitale

Repository del sito web del **Laboratorio Sanità Digitale**, iniziativa congiunta di AUSL Romagna, Università di Bologna – DISI e IRST.

Il sito è pubblicato tramite **GitHub Pages** ed è realizzato con **Jekyll**.
